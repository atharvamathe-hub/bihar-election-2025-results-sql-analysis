# 📂 Raw Dataset — Bihar Elections Results 2025

## 📌 Overview

This folder contains the original, unmodified dataset used for the SQL analysis project on the **Bihar Elections Results 2025**.

The purpose of maintaining a separate raw dataset directory is to:

- Preserve the original source data
- Ensure reproducibility of analysis
- Maintain data transparency
- Prevent accidental modification of base data

## 🗳 About the Dataset

This dataset contains complete results from the **Bihar Elections Results 2025**, scraped from the official **Election Commission of India (ECI)** results portal.

It includes results from **all 243 assembly constituencies** in Bihar.

Each row represents the performance of a single candidate in a constituency.

---

## 📁 Data Fields Included

The dataset contains the following attributes:

- Constituency Number  
- Constituency Name  
- Candidate Name  
- Party Affiliation  
- EVM (Electronic Voting Machine) Votes  
- Postal Votes  
- Total Votes Received  
- Vote Percentage  

The dataset covers:

- Major political parties  
- Minor parties  
- Independent candidates  
- NOTA (None of the Above) votes

## 🔎 Data Collection Method

- Data was collected using automated web scraping
